# Настоящий backdrop blur в KWin Overview

KWin Overview 6.7.4 показывает окна через `WindowThumbnail`. Миниатюра
рендерится в прозрачную offscreen-текстуру без рабочего стола, поэтому обычный
KWin blur/forceblur не имеет пикселей фона, которые можно размыть.

Патч `patches/kwin-6.7.4-overview-backdrop-blur.patch` создаёт GPU-размытую
копию `DesktopBackground` (`FastBlur`, radius 64), вырезает соответствующий
участок для каждого окна через `ShaderEffectSource`, ограничивает его
скруглённой маской и рисует под `WindowThumbnail`. Рабочий стол вне окон
остаётся резким.

## Статус установки 2026-08-06

В 16:43 устранена ещё одна причина, по которой Overview не запускался после
входа: модуль `org.kde.kwin.private.effects` содержит в `qmldir` директиву
`prefer :/qt/qml/...`, поэтому KWin использует AOT-копию
`WindowHeapDelegate.qml`, встроенную в `libeffectsplugin.so`, а не изменённый
QML-файл на диске. В журнале это проявлялось как `Cannot assign to
non-existent property "backdropSource"`, несмотря на наличие свойства в
установленном QML. Теперь сценарий собирает, резервирует, устанавливает и
откатывает также `libeffectsplugin.so`. SHA-256 установленного плагина:
`da566daf3a06485c65e82f070d1e58056a25f0b8f1e22d2e077153d5fb547d9e`.

Исправленная сборка установлена повторно в 16:19 MSK. В 16:25 исправлена
неполная установка: вместе с патченным бинарником теперь обязательно
устанавливается изменённый `WindowHeapDelegate.qml`; его штатная версия
сохраняется в `/var/backups/tahoe-kwin/`. Без этого Overview не загружался с
ошибкой о несуществующем свойстве `backdropSource`. Screenlocker включён;
перед установкой бинарник успешно прошёл проверку
`kwin_wayland --no-lockscreen --version`. SHA-256 установленного файла:
`cd1895763e76b096cbf45ac16526961f09850431659721d3ffbae0a9ae022584`.
Для активации нужен новый вход в Plasma или перезагрузка, после чего требуется
визуально проверить Overview.

Предыдущая сборка была **откачена** в 16:02 MSK после чёрного экрана при загрузке. Сборка с
`-DKWIN_BUILD_SCREENLOCKER=OFF` не принимала аргумент `--no-lockscreen`, с
которым `plasmalogin` запускает KWin. Сейчас `/usr/bin/kwin_wayland` совпадает
со штатной резервной копией; экран входа восстановлен.

Сценарий повторной сборки исправлен: screenlocker больше не отключается, а
собранный бинарник до установки обязан успешно выполнить
`kwin_wayland --no-lockscreen --version`. Это предотвращает повторение той же
несовместимости с `plasmalogin`.

## Откат

```bash
sudo install -m 0755 \
  /var/backups/tahoe-kwin/kwin_wayland-6.7.4-stock \
  /usr/bin/kwin_wayland
```

После отката также нужен новый вход в Plasma или перезагрузка. Обновление
пакета `kwin-wayland` перезапишет локальную сборку штатной версией.

То же самое одной командой:

```bash
tools/restore-stock-kwin-overview.sh
```

## Если эффект слетел после обновления

Проверка установленной версии и файла:

```bash
sha256sum /usr/bin/kwin_wayland
dpkg-query -W -f='${Version}\n' kwin-wayland
```

Если версия KWin всё ещё `6.7.4`, восстановить патч автоматически:

```bash
tools/rebuild-install-kwin-overview-blur.sh
```

Сценарий загружает исходник версии установленного пакета, проверяет патч,
собирает `kwin_wayland`, удаляет build-RPATH, проверяет зависимости, сохраняет
штатный бинарник и устанавливает результат. Затем нужен новый вход в Plasma
или перезагрузка.

Если KWin уже новее `6.7.4`, сценарий намеренно остановится. Сначала патч
нужно перенести на новую версию и проверить через `patch --dry-run`, иначе
можно повредить графическую сессию.
